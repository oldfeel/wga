# 权限矩阵（MVP）

角色：`owner`（会长）> `officer`（官员）> `member`（成员）。另有平台管理员 `users.is_admin`（与公会角色独立）。

未加入公会：可注册/登录、按快照/定位键 **lookup**、**创建公会**、**申请加入**、**申请认领**。

| 动作 | member | officer | owner | 平台 admin |
|------|:------:|:-------:|:-----:|:----------:|
| 查看公会信息 / 成员列表 | ✓ | ✓ | ✓ | |
| 上传本账号相关快照 | ✓ | ✓ | ✓ | |
| 查看公会内角色档案与快照 | ✓ | ✓ | ✓ | |
| CD / 专业 / 装等筛选 | ✓ | ✓ | ✓ | |
| 报名 / 改自己的报名 / 自己签到 | ✓ | ✓ | ✓ | |
| 创建 / 编辑活动 | | ✓ | ✓ | |
| 改他人报名状态 / 代签到 | | ✓ | ✓ | |
| 编辑排表 | | ✓ | ✓ | |
| 发公告 | | ✓ | ✓ | |
| 审批入会申请 | | ✓ | ✓ | |
| 修改成员角色 | | | ✓ | |
| 认证 / 拒绝公会 | | | | ✓ |
| 审批认领（通过则转移 owner 并认证） | | | | ✓ |

说明：

- 新公会创建后为 **待认证**；业务可用，UI 显示「待认证 / 已认证」。
- 「上传」不要求角色绑定必须先存在；服务端按快照内 `(realm, name)` upsert。
- 跨公会：同一用户可加入多个公会；每个请求必须指定 `guild_id`，且校验成员关系。
- 邀请码即时加入已停用。
