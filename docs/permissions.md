# 权限矩阵（MVP）

角色：`owner`（会长）> `officer`（官员）> `member`（成员）。未加入公会：仅可注册/登录/创建公会/用邀请码加入。

| 动作 | member | officer | owner |
|------|:------:|:-------:|:-----:|
| 查看公会信息 / 成员列表 | ✓ | ✓ | ✓ |
| 上传本账号相关快照 | ✓ | ✓ | ✓ |
| 查看公会内角色档案与快照 | ✓ | ✓ | ✓ |
| CD / 专业 / 装等筛选 | ✓ | ✓ | ✓ |
| 报名 / 改自己的报名 / 自己签到 | ✓ | ✓ | ✓ |
| 创建 / 编辑活动 | | ✓ | ✓ |
| 改他人报名状态 / 代签到 | | ✓ | ✓ |
| 编辑排表 | | ✓ | ✓ |
| 发公告（若启用） | | ✓ | ✓ |
| 重置邀请码 | | | ✓ |
| 修改成员角色 | | | ✓ |
| 转让会长 / 解散公会（实现期再定） | | | ✓ |

说明：

- 「上传」不要求角色绑定必须先存在；服务端按快照内 `(realm, name)` upsert，并将 `owner_user_id` 设为上传者（若该角色尚无主人或主人即为本人）。
- 跨公会：同一用户可加入多个公会；每个请求必须指定 `guild_id`，且校验成员关系。
